# ジョージで学ぶ話さがし

「何を学ばせたいか」から、おさるのジョージ（テレビアニメ）の話を探せるWebアプリです。全389話（シーズン1〜15）に対応しています。

## できること
- 学びの目的（かず、宇宙と星、気持ち・こころ など23種類）から探す
- 生活の困りごと・季節や行事・ことば・年齢・キャラクター・シーズンで絞り込む
- Amazon Prime Videoの該当シーズンのページを開く（何話目かも表示）
- 「見た」「お気に入り」を記録する
- 各話にメモを書く、内容を修正する（カテゴリー・年齢・舞台・国・季節・困りごと・キャラクターはプルダウンから複数選択）
- 選択肢そのものを「選択肢の管理」で追加・名前変更・削除する
- メモ・修正をバックアップとして書き出し／読み込み、修正を反映したCSVを書き出す

記録・メモ・修正はこの端末のブラウザにだけ保存されます。
- 条件に合う話から「おまかせで1話」を選ぶ

## ファイル構成
- `index.html` … アプリ本体（データも中に入っています。ビルド不要）
- `manifest.json` / `icons/` … ホーム画面に追加したときのアイコンと名前
- `data/osaru_george_all.csv` … 元データ（14列、UTF-8）

## 公開方法
Settings → Pages → Branch を `main` / `(root)` にして保存すると、`https://no-f9.github.io/CG-episode-finder/` で開けます。
iPhone・iPadでは、Safariの共有メニュー →「ホーム画面に追加」でアプリのように使えます。

## データについて
あらすじと分類（学びの分野・困りごと・季節・家でできること）は公開情報をもとにした独自のまとめで、公式のものではありません。
邦題と原題の対応は日本語版Wikipediaの放送リストに基づきます。
